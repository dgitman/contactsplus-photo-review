# Contacts+ Photo Review

See the [repository README](../README.md) for the private workflow, configuration, and limitations.

The local server reads and writes Contacts+ only. Refresh loads current photos; Review and Apply commit the explicitly previewed photo changes with backups and readback verification. Protected contacts are viewable but cannot be changed. Local files store review choices, cached previews, and recovery data. There is no integration with the macOS Contacts database or iCloud.
